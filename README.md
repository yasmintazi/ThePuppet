# The Puppet

A 3D modeled horror-themed room scene created in Autodesk 3ds Max, featuring a monster, chains, a locked cupboard, and other eerie props.

## Project Structure

- `assets/` — 3ds Max scene files (`.max`) and the final exported scene (`.fbx`)
  - `yasmin_room_finalscene.max` — main room scene
  - `yasmin_finalscene.fbx` — final exported scene
  - `yasmin_chains.max`, `yasmin_chair.max`, `yasmin_clock.max`, `yasmin_cupboard.max`, `yasmin_door.max`, `yasmin_light.max`, `yasmin_lock.max`, `yasmin_lockholder.max`, `yasmin_monster.max`, `yasmin_table.max` — individual prop models
- `textures/` — texture maps (diffuse, bump, alpha) used across the scene
- `pics/` — reference/preview images

## Software

- Autodesk 3ds Max
- 3ds Max FBX exporter
